# SteadySignal Tech | Reliable IT Support

A responsive, static website for SteadySignal Tech, an IT services business. The logo is an SVG at `assets/logo.svg`.

## Customize the site

- Connect the quote form in `index.html` to a form endpoint before accepting submissions; its submit button is currently disabled.
- Edit `index.html` to update service descriptions and business details.
- Replace `assets/logo.svg` to update the logo used in the header, footer, and browser tab.
- Update the custom service illustrations in `assets/illustration-*.svg` and `assets/hero-signal.svg`.
- Update `assets/css/styles.css` to change the colors, layout, and typography.
- Update `assets/js/script.js` for the responsive navigation, Explore services scrolling, and three-step quote form.
- No build tools or package installation are required.

## Publish with GitHub Pages

The site is configured to publish from the `main` branch at the repository root. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. GitHub will provide the published website URL after the first deployment.
